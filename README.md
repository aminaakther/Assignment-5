1️⃣ var, let, and const – Simple Version
var → Old style, works inside functions, can change and be re-declared.
let → Modern, works in blocks,
can change but not re-declared.const → Constant, works in blocks, cannot change or be re-declared


2️⃣ Spread Operator (...) – Another Way
The spread operator (...) takes all elements from an array or object and inserts them somewhere else.


3️⃣ map(), filter(), and forEach() – Another Way
map() → Changes every item in an array and gives a new array.
filter() → Picks items that match a condition and gives a new array.
forEach() → Goes through each item but doesn’t create a new array.


4️⃣ Arrow Function – Another Way
An arrow function is a compact way to write functions in JavaScript


5️⃣ Template Literals – Another Way
Template literals let you write strings easily with variables and multiple lines using backticks
